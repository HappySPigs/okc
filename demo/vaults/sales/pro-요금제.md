# Pro 요금제

Pro 요금제는 Free에서 시작한 팀이 규모가 커질 때 올라가는 유료 플랜이다. 워크스페이스 단위 정액제로 제공되며, 좌석 수 제한 없이 팀 전체가 사용할 수 있다.

가격은 **Pro 요금제는 월 $49**이다. 연간 결제 시 두 달치 할인이 적용된다.

Pro에서는 고급 권한 관리, 통합 기능, 우선 지원이 포함된다. 더 큰 조직이 SSO와 감사 로그를 필요로 하면 Enterprise로 안내한다. 요금제 비교표는 온보딩 자료에 포함되어 고객에게 제공된다.
