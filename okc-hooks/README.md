# okc-hooks

Obsidian vault 변경을 감지하고 okc-web으로 자동 업로드하는 로컬 데몬입니다. 파일 이벤트, 시작 시 스캔,
주기 스캔, 재시도, 재개 업로드를 지원합니다. 병합과 통합 vault 제공은 okc-web이 담당합니다.
